01

Green AILocal inference, measured.

Research

Benchmarking energy use in local language-model inference, comparing estimates from CodeCarbon and pyJoules.

  • Python
  • Bash
  • Ollama
  • Intel RAPL / NVML
Source ↗
More details about Green AI

Approach

Python scripts run inference on open-source small language models available through Ollama. The work compares two energy-estimation libraries, CodeCarbon and pyJoules, using CPU and GPU measurements through Intel RAPL and NVML.

Implementation

A Bash script automates virtual-environment setup, dependency checks, and benchmark execution. Separate Python scripts process the measurements and produce plots for comparison.

Scope

The focus is local inference and measurement tooling, not model training. The repository contains the scripts; no universal energy-saving claim is implied by the comparison.

Implementation

React components and TypeScript power the interface, with Tailwind CSS for styling. Browser localStorage provides persistence without a backend database.

Trade-off

Data stays in the browser where it was created. This version does not provide account-based cross-device synchronization; clearing site storage removes locally saved data.

Architecture

The application uses Java with an MVC structure, runs on Tomcat, and accesses MySQL through JDBC. HTML, CSS, and JavaScript provide the responsive interface.

Features

Account authentication uses password hashing. An admin dashboard supports store management, while the shopping cart keeps state in the session and uses AJAX for updates.

Scope

This is an ecommerce prototype, presented as source code rather than a live production shop.
